## 🧹 数据清洗亮点

### ✅ 空值治理（工程级）
- 使用 `pd.NA` 统一空值语义
- 通过 `fillna()` 集中兜底
- 区分 `"无" / "未提供" / "空"` 等业务含义

### ✅ 字段标准化
- 税率、金额：清洗非数字字符 → 转为数值 → 保留两位小数
- 日期：统一为 `datetime64[ns]`
- 状态 / 部门：完成中英文映射，符合财务系统规范

### ✅ 精度与显示控制
- 从源头使用 `.round(2)` 控制金额精度
- 使用 `pd.options.display.float_format` 消除科学计数法
- 输出结果符合“元 / 分”财务精度要求
