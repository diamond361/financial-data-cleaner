# 财务数据自动化清洗工具

> 一个用Python实现的、专业的财务数据清洗脚本，用于处理企业财务数据中的常见质量问题。

## ✨ 项目亮点
- **完整流程**：从数据加载、问题诊断、智能清洗到结果验证的完整数据处理流程
- **专业级清洗**：不仅处理NaN，还能智能处理空字符串、空格、特殊空值标记等多种“假空值”
- **财务业务理解**：针对财务数据特性（如订单编号完整性、客户信息完整性）进行专项清洗
- **可复用性强**：模块化设计，易于适配不同企业的财务数据格式

## 🚀 核心功能
1. **智能空值处理**
   - 自动识别并统一处理：NaN、空字符串`""`、空格`" "`、特殊标记（null/NULL/NA）
   - 按业务规则智能填充：客户姓名→"未知客户"，销售员→"未分配"
   
2. **数据质量保障**
   - 强制保证主键（订单编号）完整性
   - 清洗前后数据验证，确保无遗漏问题
   - 生成可直接用于分析的干净Excel文件

3. **专业输出**
   - 输出无多余索引列的整洁Excel文件
   - 详细的清洗过程日志和验证报告

## 🛠️ 技术栈
- **Python 3.x**
- **pandas** - 数据处理核心库
- **numpy** - 数值计算和空值处理
- **正则表达式** - 复杂文本模式匹配
